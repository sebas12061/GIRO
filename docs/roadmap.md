# Roadmap inicial de GIRO

## Fase 1 — Base del proyecto

- Crear repositorio
- Definir estructura monolítica modular
- Configurar backend y frontend
- Configurar PostgreSQL y Docker
- Preparar autenticación y navegación

## Fase 2 — Seguridad y configuración

- Login y usuarios
- Roles y permisos
- Gestión de restaurantes
- Mesas y configuraciones básicas

## Fase 3 — Catálogo y menú

- Categorías
- Productos
- Unidades operativas
- Menús y opciones
- Precios

## Fase 4 — Pedidos y cocina

- Crear pedidos
- Modificar pedidos abiertos
- Cancelar pedidos
- Consultar pedidos pendientes
- Estado de preparación

## Fase 5 — Ventas y pagos

- Generar ventas al cobro
- Efectivo, transferencia, fiados
- Múltiples pagos por venta
- Validación de transferencias

## Fase 6 — Caja y finanzas

- Apertura y base inicial
- Gastos y movimientos
- Cálculo de efectivo esperado
- Diferencia y cierre
- Cuadre de caja

## Fase 7 — Compras y stock

- Proveedores
- Compras
- Movimientos de inventario
- Cierre operativo
- Existencias finales

## Fase 8 — Reportes y auditoría

- Ventas por período
- Gastos y compras
- Fiados
- Movimientos de caja
- Historial de cambios
- Auditoría crítica

## Fase 9 — Optimización multi-dispositivo

- Ajustes responsive para tablet
- Optimización móvil
- Flujos rápidos para ventas y cocina
- Experiencia adaptada por rol

## Fase 10 — Despliegue y validación

- Dockerización final
- Tests de integración
- Validación de flujo principal
- Preparación para entorno de producción

## Principio guía

Se priorizará primero lo que hace funcionar la operación diaria: pedidos, cocina, ventas, caja, inventario y reportes.
